?? OpenSpec Specifications (Nexus Protocol V3.1)
Este diretório armazena especificações funcionais e técnicas complementares do ecossistema Body Harmony.


??? Estrutura da Governança OpenSpec
openspec/master/: A fonte única de verdade (SSOT) para arquitetura perene, schemas e regras centrais.
openspec/contracts/: Schemas JSON formais de todos os endpoints HTTP e contratos de dados.
openspec/deltas/: Planos atômicos em andamento (PLAN-*.md).
openspec/tracker/: Rastreamento vivo da execução (task.md).
openspec/archive/: Histórico permanente de deltas, relatórios e versões arquivadas.
openspec/templates/: Modelos oficiais padronizados (TEMPLATE_PLAN.md, TEMPLATE_MASTER.md).
